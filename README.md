# IndianConsulate.com — Independent Consular Services Guide

An independent, AdSense-monetised guide to Indian consular services worldwide (OCI & e-OCI, passport renewal abroad, visas & e-Visa, surrender certificates, attestation/apostille, PCC, emergencies, NRI services). It includes free interactive tools, a lead-generation help desk, donations, contests, careers and sponsorships.

**Not a government website.** Every page carries a non-affiliation notice. The site never uses the State Emblem of India and links users to official `.gov.in` portals.

## How the site is built
GitHub Pages builds the site itself (free plan, branch `main`, folder `/ (root)`) using its built-in Jekyll step. No Actions are required.

| Path | What it is |
|---|---|
| `*.html`, `services/`, `tools/`, `guides/` | One small file per page: front matter only (title, description, type, `src`) |
| `build/content/**.html` | The page bodies, rendered through the layout |
| `_layouts/default.html` | Shared shell. Contains the owner contact strip (→ web.works/contact), the independence bar, header/nav, breadcrumbs, the article wrapper, footer with trademark notice, cookie notice, AdSense tag and JSON-LD |
| `build/partials/tokens.html` | Shared blocks used inside page bodies: `{{cta}}`, `{{support}}`, `{{directory}}`, `{{news}}`, `{{videos}}`, `{{guides}}` … |
| `build/data/missions.json` | Consulate-finder data (83 missions, 58 countries) |
| `build/data/news.json` | Headline feed (refreshed by the daily job) |
| `build/data/videos.json` | Video topics. To add click-to-play embeds, add `{"id": "<YouTube ID>", "title": "…"}` objects to `embeds` |
| `build/fetch_news.py` | Pulls headlines (title + link only) from Google News RSS |
| `automation/auto-update.yml` | Daily news-refresh workflow (see below) |
| `assets/js/config.js` | **Edit me:** donation links, contest prizes, encoded form-relay key |
| `assets/js/main.js` · `tools.js` · `extra.js` | UI, lead forms, donations, search · interactive tools · table of contents and live news |
| `assets/data/search-index.json`, `robots.txt` | Generated by Jekyll. `sitemap.xml` comes from the `jekyll-sitemap` plugin |
| `PROMPTS.md` · `RESEARCH.md` | Phase-wise build prompts · source and competitor survey (excluded from the public site) |

To add a page: put the body in `build/content/<path>.html`, then create `<path>.html` with front matter (`title`, `description`, `type`, `src: "content/<path>.html"`). For guides, also add `kind: "guide"` and `order`.

## Publish on GitHub Pages (one-time)
Signed in as **WEBWORKSA1**: Settings → Pages → Build and deployment → Source **Deploy from a branch** → Branch **main**, folder **/ (root)** → Save.
The site goes live at `https://webworksa1.github.io/indianconsulate-com/` within a few minutes.

## Turn on daily automation (optional, one-time)
Copy `automation/auto-update.yml` into a new file at `.github/workflows/auto-update.yml` (Add file → Create new file). Each day it refreshes the news feed and commits it, and Pages then rebuilds. That rebuild also refreshes the "Reviewed <month>" dates and the sitemap. The News page also pulls in live headlines in the browser.

## Custom domain (indianconsulate.com)
The domain currently points to a registrar parking page. When you're ready:

3. In `_config.yml` set `url: "https://indianconsulate.com"` and `baseurl: ""`, then commit.

## Forms (lead gen, contact, pledges, contest, careers, partners, newsletter)
All forms post via FormSubmit to the owner inbox. The address is assembled at runtime from the encoded `relay` key in `config.js` and never appears in page source. **The first submission triggers a one-time FormSubmit activation email. Click Activate**, otherwise later submissions are not delivered. Lead submissions include service, country, urgency, citizenship, a 0–100 lead score, first landing page, referrer and UTM tags.

## Donations
Paste PayPal.me / Stripe Payment Link / Buy Me a Coffee / Razorpay / UPI URLs into `assets/js/config.js` → `payments`. Until you do, the Support page runs in pledge mode: the pledge form comes to you, and you email the supporter a payment link.

## AdSense
The Auto-ads tag (`ca-pub-6620975821265271`) is in the `<head>` of every content page. It is deliberately left off `get-help.html`, `thank-you.html` and `404.html` to keep the lead funnel clean. `ads.txt` is at the root.
- Apply once the custom domain is live; `https://indianconsulate.com/ads.txt` must resolve.
- After approval, enable Auto ads and turn on the Google-certified consent message for EEA/UK/CH (Privacy & messaging).

## Contest
Runs monthly, and the countdown resets automatically each month. Change prizes in `config.js`.
